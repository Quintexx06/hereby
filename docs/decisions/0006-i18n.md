# 0006: Internationalisation per household

**Status:** Accepted (2026-10-06)

## Context
Guests read in German (Swiss spelling), French, Italian or English, set per
household, and mixed-language guest lists are normal.

## Decision
- `Locale` enum: `de_CH`, `fr`, `it`, `en`. Stored per household, with a
  default per wedding.
- Copy lives in Laravel's `lang/{locale}/*.php`. The groups listed in
  `App\Support\FrontendTranslations::GROUPS` are shared lazily with Inertia as
  `translations`, together with `locale`.
- Vue reads them with `useTrans()`: `t('invitation.reply_by', { date })`.
  There's no extra i18n dependency.
- Dates, times and lists are formatted with `Intl` (`lib/format.ts`) in the
  **venue's time zone** (Europe/Zurich), never the guest's.
- de-CH copy uses Swiss spelling (no "ß"). Every language gets one native
  review of the invitation and RSVP wording before the first wedding.

## Consequences
- Keep the shared groups small; split by page if they grow.
- Couple-written content (stories, travel text) is per-wedding data, not `lang/` files.
  It needs its own translatable fields in Phase 1.
