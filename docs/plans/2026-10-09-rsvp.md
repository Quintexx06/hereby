# Plan: the 60-second RSVP

Spec: [2026-10-09-rsvp-design](../specs/2026-10-09-rsvp-design.md). Roadmap: 1.4

## Backend

- [x] Migration: weddings gain `menu_options`, `children_menu`, `offers_shuttle`, `offers_stay`, `asks_song`; households gain `shuttle_seats`, `needs_stay`, `song_wish`, `responded_at`
- [x] Models: casts and fillables. `Wedding::acceptsReplies()` (deadline not passed), `Wedding::menuKeys()`
- [x] `ReplyFormResource` (household, guests, events, its answers, the couple's questions; `hasDietaryNotes` flag only)
- [x] `ShowReplyController` (GET `/i/{token}/antwort`) and `SaveReplyController` (PUT), in the household's locale (`UseHouseholdLocale`) and throttled like the invitation
- [x] `SaveReplyRequest`: answers per guest × invited event, a menu only where it applies, ids scoped to the household and its events, refused after the deadline
- [x] `SaveReply` action: responses upsert, dietary notes (keep when blank, clear on request), plus-one create/update/delete, household extras only when offered, `responded_at`
- [x] Invitation resource gains `reply` (summary) and `rsvpOpen`
- [x] Couple side: `RsvpSettingsController` (show/update) + `UpdateRsvpSettingsRequest`, behind `can:update,wedding`

## Frontend
