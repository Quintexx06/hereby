# Hereby

> _I, the undersigned, hereby…_: put it in writing.

Laravel 13 · Inertia v3 · Vue 3 · TypeScript · Tailwind v4 · shadcn-vue · GSAP

## Getting started

```bash
composer setup     # install deps, .env, key, migrate, build
composer dev       # app + queue + logs + vite on http://localhost:8000
composer ci:check  # lint, types, Pint, PHPStan, tests
```
